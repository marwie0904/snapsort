# Image Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `search()` and `snapsort search <image>`, which rank ingested media by similarity to a query image using stored `image_embed` vectors.

**Architecture:** `snapsort/search.py` decodes and embeds the query with the `image_embed` module, reads current `image_embed` vectors from SQLite with one `SELECT`, scores them with a numpy matrix product, and keeps the best frame per media file. `snapsort/cli.py` gets a `search` subcommand that calls `search()` and prints one line per match.

**Tech Stack:** Python 3.12, sqlite3, numpy, the existing `ImageEmbed` module (DINOv2-base), argparse, pytest.

**Spec:** `docs/design/2026-10-09-search.md`. It builds on `docs/design/2026-10-09-ingest-pipeline.md` (storage schema, CLI) and `docs/design/2026-10-09-image-embedder.md` (`ImageEmbed.embed`).

## Global Constraints

- Python 3.12. No new dependencies.
- Search never writes. It never creates `snapsort.db` and never calls `snapsort.ingest.connect` (which creates the database and schema).
- Candidate vectors: `results.module = 'image_embed'` whose media has a `runs` row for `image_embed` with `status = 'done'` and `version = ImageEmbed.version`.
- Query decoding: `snapsort.ingest.load_image`. Query embedding: `ImageEmbed.embed`.
- Defaults: `limit = 20`, `min_score = 0.5`.
- CLI: matches → exit 0. No match → prints `no matches at or above <min_score with 2 decimals>`, exit 0. `SearchError` → `error: <message>` on stderr, exit 2.
- `cli.py` imports `snapsort.search` lazily, inside the `search` branch, so renaming `image_embed.py` to disable it cannot break `snapsort ingest`.
- No README changes.
- Commit messages have no `Co-Authored-By` lines.

## Review Focus

1. A relative query path typed in a shell (`snapsort search media/red.png`) must resolve against the current directory. Pinned by `test_cli_prints_matches` in Task 2.
2. Uppercase extensions from phones and cameras (`IMG_0001.JPG`, `.PNG`) must be accepted as images. Pinned by `test_uppercase_extension_query` in Task 1.
3. A file whose `image_embed` run errored keeps its old results in the database. Those must not be searched. Pinned by `test_unfinished_or_stale_runs_are_skipped[status-error]` in Task 1.
4. Videos longer than a minute or an hour must print `m:ss` with minutes past 59 (`1:05`, `62:05`). Pinned by `test_format_match` in Task 2.
5. `--limit 0` or a negative limit must be an error, not a silent slice (`matches[:-1]` would drop the last match). Pinned by `test_limit_below_one_is_an_error` in Task 1.

- [ ] **Step 3: Write `snapsort/search.py`**

```python
"""Image search: rank ingested media by similarity to a query image."""
import functools
import sqlite3
from contextlib import closing
from dataclasses import dataclass
from pathlib import Path

import numpy as np

from snapsort.ingest import classify, load_image
from snapsort.modules.image_embed import ImageEmbed

HINT = "run: snapsort ingest <path> --modules image_embed"

# Vectors of media whose image_embed run finished at the current module version. Older or
# errored runs keep stale vectors, which would score wrongly against the current model.
VECTORS = """
SELECT m.path, m.kind, f.ts, r.vector
FROM results r
JOIN frames f ON f.id = r.frame_id
JOIN media m ON m.id = f.media_id
JOIN runs u ON u.media_id = m.id AND u.module = r.module
WHERE r.module = ? AND u.status = 'done' AND u.version = ?
"""


@dataclass(frozen=True)
class Match:
    path: str           # absolute media path, as stored
    kind: str           # "image" | "video"
    score: float        # dot product of unit vectors (cosine), -1 to 1
    ts: float | None    # video: second of the best-matching frame; image: None


class SearchError(Exception):
    """The query or the library can't be searched."""


@functools.cache
def _embedder() -> ImageEmbed:
    """One loaded model per process."""
    m = ImageEmbed()
    m.setup()
    return m


def search(query: Path, data_dir: Path, limit: int = 20, min_score: float = 0.5) -> list[Match]:
    """Media most similar to the query image, best first, one Match per media file."""
    if limit < 1:
        raise SearchError(f"limit must be at least 1, got {limit}")
    if classify(query) != "image":
        raise SearchError(f"query must be an image (jpg, jpeg, png, webp, heic): {query}")
    try:
        image = load_image(query)
    except OSError as e:
        raise SearchError(f"cannot read query {query}: {e}") from e
    db = data_dir / "snapsort.db"
    if not db.exists():
        raise SearchError(f"nothing ingested in {data_dir}; {HINT}")
    with closing(sqlite3.connect(db)) as conn:
        rows = conn.execute(VECTORS, (ImageEmbed.name, ImageEmbed.version)).fetchall()
    if not rows:
        raise SearchError(f"no current image_embed vectors in {db}; {HINT}")

    q = _embedder().embed([image])[0]
    scores = np.frombuffer(b"".join(r[3] for r in rows), "<f4").reshape(len(rows), -1) @ q
    best: dict[str, Match] = {}
    for (path, kind, ts, _), score in zip(rows, scores.tolist()):
        if path not in best or score > best[path].score:
            best[path] = Match(path, kind, score, ts)
    matches = sorted((m for m in best.values() if m.score >= min_score), key=lambda m: -m.score)
    return matches[:limit]
```

```python
def format_match(m) -> str:
    """One output line for a search Match: score, path, and m:ss of the best frame for videos."""
    at = "" if m.ts is None else f" @ {int(m.ts) // 60}:{int(m.ts) % 60:02d}"
    return f"{m.score:.3f}  {m.path}{at}"
```
